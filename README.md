## ⚡ What is Aether?

**Aether**는 단순한 오피스 스위트가 아닙니다.  
클라우드 빅테크의 데이터 수집, ISP 검열, 폐쇄형 SaaS 의존에서 완전히 벗어나기 위해 설계된 **차세대 주권형 데스크톱 하이퍼 플랫폼(Sovereign HyperOffice & Intelligence Workspace)**입니다.

북유럽 신화의 세계수를 모티브로 설계된 **8대 핵심 서브시스템(Nordic Octa-Engine)**이 유기적으로 결합되어, 워드/엑셀/파워포인트 문서 작성부터 다중 탭 Tor 브라우징, Apple Silicon M4 기반 오프라인 로컬 LLM, 패킷 분할 안티 DPI VPN, 영지식 암호화 금고, 양방향 지식 그래프까지 단 하나의 통합 앱에서 무결하게 실행됩니다.

## 🏛️ The 8 Nordic Subsystems

### 1. 🌐 Aetherum — Privacy-Hardened Multi-Tab Tor Browser
> *“No trackers. No fingerprints. Pure uncompromised web freedom.”*

* **Native Multi-Layer Adblock & Tracker Shield**: 네트워크 레벨 광고/트래커/팝업 실시간 차단(글로벌 애드테크 + 네이버·다음·카카오 등 국내 광고 서버 KR-Shield), EasyList CSS 빈 광고 슬롯 제거, 유튜브 프리롤 광고 자동 스킵, `utm_*`·`fbclid`·`gclid` 추적 파라미터 자동 정제 및 도메인별 화이트리스트/커스텀 필터(`aetherum://adblock`) 기본 내장.
* **Native Multi-Tab Workspace**: Chrome 스타일의 직관적인 다중 탭 인터페이스(`⌘T`, `⌘W`, `⌘1`~`⌘9`). 탭 간 독립된 뷰포트 상태 보존.
* **Onion Routing SOCKS5**: 토르 데몬(포트 9050) 연동을 통한 `.onion` 히든 서비스 및 다크웹 보안 브라우징. 원클릭 토르 토글 지원.
* **Flawless Redirection & OAuth**: Chromium 131 순정 헤더 및 `sec-ch-ua` 클라이언트 힌트 적용으로 Proton Mail, Google, Microsoft 365, Turnstile 등 까다로운 로그인/리디렉션 완벽 호환.
* **AI Page Intelligence**: Gemini 기반 원클릭 웹페이지 3줄 요약 & 핵심 분석 사이드 드로어 내장.
* **One-Click Word Export**: 현재 웹페이지의 본문을 정제하여 즉시 `.docx` 또는 `.md` 문서로 로컬 저장.

### 2. 📜 Yggdrasil — Hyper-Integrated Developer Terminal
> *“The command center connecting the machine to the cosmos.”*

* **Real PTY Interactive Shell**: macOS `zsh` 및 리눅스 `bash` 기반 네이티브 가상 터미널. ANSI 풀컬러 렌더링 및 인터랙티브 CLI 완벽 구동.
* **Nordic Preset Bar**: Tor 상태 진단, Homebrew 환경 점검, Ollama 로컬 모델 목록, `aether --help` 등 빈번한 작업을 원클릭 실행.
* **Cross-Frame Session Resilience**: 백그라운드 PTY 세션 자동 복구 및 실시간 리사이징 지원.

### 3. 🛡️ Sleipnir — Anti-DPI HTTPS SNI Splitting Engine
> *“Galloping through firewalls and Deep Packet Inspection without a trace.”*

* **SNI Packet Fragmentation**: 차단 장비(SNI 감청/검열)를 무력화하기 위해 TLS ClientHello 패킷의 도메인 헤더를 실시간 바이트 단위로 쪼개어 전송.
* **Zero Speed Penalty**: VPN처럼 제3자 서버를 거치지 않고 로컬 프록시(포트 8087)에서 패킷 구조만 변조하므로 회선 최고 속도 100% 유지.
* **Fail-Safe Socket Recovery**: 빠른 연타 토글 시에도 포트 충돌 없이 우아하게 자원을 반환하는 복원력 아키텍처.

### 4. 🧠 Mímisbrunnr — Airgapped Local Intelligence Assistant
> *“Your private intellect running directly on Apple Silicon M4 unified memory.”*

* **100% Airgapped Privacy**: 단 하나의 토큰도 외부 서버로 전송되지 않는 완벽한 오프라인 신경망 인텔리전스.
* **Dual Sovereign Engine Suite (Strictly 2 Models)**:
  1. `PocketAiHub/Qwen3.8-9B-Abliterated-MLX/4bit` — Apple MLX 네이티브 4-bit 직교 가중치 거절 제거(Abliterated) 9B 고속 모델 (`5.57 GiB`)
  2. `qwen2.5:7b` — 고속 Apple Metal 기반 Ollama 7B 엔진 (`4.7 GB`)
* **Apple Silicon M4 Hardware & VRAM Guard**: 16GB 통일 메모리(Unified Memory) 내 스왑 방지를 위해 두 모델 전환 시 비활성 엔진의 VRAM을 즉시 자동 반환(`gc.collect()` + `mx.clear_cache()` / Ollama `keep_alive: 0`).
* **Full Control Controls**: 2개 전용 모델 선택자(Model Selector), 온도 슬라이더, 사용자 정의 시스템 디렉티브(System Directive) 편집기 내장.
* **Multi-Task Neural Presets**:
  * ⚡ *Full Control*: 검열 및 거부 프로토콜 없는 무제한 직접 질의
  * 🛡️ *Yggdrasil Script Audit*: 셸 스크립트 및 런처 내 위험 명령어 사전 감사
  * ✉️ *ProtonMail Thread Digest*: 암호화된 메일 본문 핵심 요약
  * 💻 *Secure Code Synthesizer*: 프라이버시 중심의 안전한 코드 생성

### 5. 🐉 Fafnir Vault — Zero-Knowledge AES-256 Safe
> *“A dragon's hoard guarded by military-grade authenticated cryptography.”*

* **Authenticated Encryption**: `AES-256-GCM` 알고리즘과 `PBKDF2` (100,000 iterations, SHA-256 Salt) 기반 영지식 보안.
* **Encrypted Storage (`~/.aether/fafnir_vault`)**: 메타데이터, 파일명, 무결성 태그(Auth Tag)까지 암호문과 함께 단일 컨테이너로 패키징.
* **Direct-to-Desktop Decryption**: 메모리 상에서 복호화 후 사용자의 바탕화면으로 즉시 추출. 임시 평문 잔재 영구 제거.

### 6. 🗝️ Nibelungen — Local-First Knowledge Graph & Wiki
> *“Interweave your thoughts in a resilient, bidirectional second brain.”*

* **Bidirectional Wikilinks**: `[[Note Name]]` 문법을 통한 지식 네트워크 실시간 링크.
* **Obsidian-Style Interactive Canvas**: SVG 기반 역동적 힘 지향(Force-Directed) 그래프 시각화. 노드 드래그, 링크 탐색, 줌/팬 지원.
* **Markdown Native (`~/.aether/nibelungen`)**: 독점 바이너리 포맷이 아닌 순수 `.md` 파일 기반 로컬 동기화 및 즉시 검색.

### 7. 🐿️ Ratatoskr — Visual API Client & SQLite Inspector
> *“The agile messenger traversing networks and relational databases.”*

* **Tor-Tunneled HTTP Client**: SOCKS5 프록시를 경유하여 API 요청을 전송. IP 유출 없는 보안 API 디버깅.
* **Built-in Tor & Cloudflare DoH Presets**: 원클릭 익명성 테스트 및 보안 DNS 응답 감사.
* **Live SQLite Database Studio**: 데이터베이스 테이블 스키마 자동 탐색, 인라인 SQL 쿼리 러너, 인터랙티브 데이터 그리드 뷰어.

### 8. 🎙️ Heimdall — Acoustic Biometric Diarization & AI Audio Summarizer
> *“The all-hearing guardian capturing voices, separating speakers, and distilling clarity.”*

* **Real-Time Acoustic DSP & 3 Cybernetic Visualizers**: 60fps HTML5 Canvas 기반 `Jarvis Wave`, `Siri Hologram`, `Cyber Spectrum` 실시간 음향 시각화 및 자기상관(Autocorrelation) 기본 주파수(F0 피치, 75~350Hz) 성문 추적.
* **Biometric Speaker Diarization & Cough Filter**: 화자별 음향 피치 학습 자동 분리(`화자 1`, `화자 2`, `화자 3`) + 기침·타이핑 등 비조화 충격 소음 자동 배제 게이트, 실시간 마이크 녹음 및 오디오 파일(`.wav`, `.mp3`, `.m4a`, `.ogg`, `.flac`, `.webm`) 일괄 화자 분리 지원.
* **Gemini Flash-Lite Executive Summary & Token Telemetry**: `.env`의 `GEMINI_API_KEY` 보안 연동(잠금/변조 방지 지원)을 통한 구조화된 회의 요약, 실시간 **소모 토큰 수(입력/오디오/생성)** 및 **잔여 토큰 백분율(`% Left`)** 정밀 모니터링, Nibelungen 지식 그래프 원클릭 연동.

### 9. 💻 Aether CLI (`aether`) — Headless Document Engine
> *“The same parser, the same writer, the same renderer — on your terminal.”*

앱에서 사용하는 동일한 고성능 CJS 엔진(`genoffice.cjs`)을 헤드리스 CLI로 제공합니다.

```sh
# 전체 사용법 안내
aether --help

# 엑셀/스프레드시트 읽기 및 수정
aether sheet read report.xlsx

# 파워포인트 슬라이드 AI 검사 및 재생성
aether slides audit deck.pptx

# 마이크로소프트 워드 문서 생성 및 변환
aether convert input.md output.docx

# Model Context Protocol (MCP) 서버 구동 (Claude Code, Codex, Cursor 연동)
aether mcp install all
```

## 🚀 Quick Start

### 1. 다운로드 및 실행 (macOS)
```sh
# 최신 릴리스 패키지 다운로드 후 실행
open /Applications/Aether.app
# 또는
open /Users/$USER/Desktop/Aether.app
```

### 2. CLI 전역 환경변수 등록
```sh
aether install-cli
# 또는
ln -sf /Applications/Aether.app/Contents/Resources/cli/aether ~/.local/bin/aether
```

## 🛡️ Security & Privacy Manifesto

1. **Airgapped by Design**: 사용자의 프롬프트, 개인 메모, 로컬 코드는 절대 외부 클라우드로 무단 전송되지 않습니다.
2. **Zero Plaintext at Rest**: Fafnir에 보관되는 모든 민감 데이터는 업계 표준 AES-256-GCM으로 봉인됩니다.
3. **ISP Censorship Defeat**: Sleipnir는 국가 및 통신사 차원의 SNI 패킷 차단을 원천 분쇄합니다.
4. **Anonymity Preserved**: Aetherum은 토르 네트워크를 통해 IP 주소와 브라우저 핑거프린트를 난독화합니다.
